# Yug Adda release checklist

- [ ] Choose final Android application ID and iOS bundle ID.
- [ ] Create Firebase staging and production projects under the owner's Google account.
- [ ] Register Android/iOS apps in Firebase and configure authentication providers.
- [ ] Add FlutterFire packages and initialize Firebase in Flutter.
- [ ] Implement and test auth, account deletion, profile, communities, posts, polls, chat, media, notifications.
- [ ] Implement moderation/report/block flows and privacy policy/terms.
- [ ] Complete consent and access policy before any location sharing; current rules deny location access.
- [ ] Add real call provider and map provider only after selecting vendors and reviewing costs/privacy.
- [ ] Run Firebase Emulator tests, Flutter tests, accessibility checks, and physical-device tests.
- [ ] Configure app signing and build release artifacts.
- [ ] Prepare store screenshots, descriptions, age/content ratings, privacy disclosures, and support contact.
- [ ] Owner submits through Google Play Console and Apple App Store Connect and responds to review feedback.
