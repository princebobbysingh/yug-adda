# yug-adda — Phase 2 Flutter UI

This package is a runnable Flutter UI foundation for yug-adda.

## Run
1. Install Flutter SDK and Android Studio (or Xcode for iOS).
2. From this folder run `flutter pub get`.
3. Run `flutter run` with an emulator or device connected.

## Included in this phase
- Modern dark-purple Material 3 theme and bottom navigation
- Bengali, English, and Hindi language selector with core navigation labels
- Local demo feed, create-post dialog, like toggle, poll selection
- Public/private community cards with local join toggle
- Consent-first map placeholder, chat list, profile settings

## Not connected yet
No production authentication, server/database, media uploads, live chat, calling, push notifications, real maps/location sharing, app-store signing, or publishing. UI interactions marked demo are local-only. Do not use for production or collect real user data.
